# Maestro 19 — ขายคอนโด

หน้าเว็บขายห้อง Maestro 19 อาคาร D ชั้น 2 · 1 ห้องนอน ~40 ตร.ม. · เลี้ยงสัตว์ได้

- `index.html` — หน้าเว็บทั้งหมด (HTML/CSS/JS ไฟล์เดียว, แปลน 3D ใช้ three.js จาก CDN)
- `images/` — รูปห้อง รูปส่วนกลาง และแปลน

แก้ราคา / เบอร์โทร / LINE ได้ที่ `CONFIG` ด้านบนของ `<script>` ใน `index.html`
